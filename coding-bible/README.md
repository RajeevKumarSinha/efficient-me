# The Universal AI-Proof Coding Bible & Engineering Framework

> **Mission**: A battle-tested, copy-pasteable framework designed for rapid kickstarting and continuous development of **efficient, secure, lightning-fast, lightweight, and 100% open-source applications**. 
>
> When this folder is present in any repository, it establishes unbreakable guardrails that prevent AI agents from making silly, subtle, or catastrophic mistakes across all scales.

## 🚀 How to Use This in Any New Project

1. Copy the `coding-bible/` folder and `AGENTS.md` into the root of your new project.
2. If using Antigravity IDE, copy `.agents/` as well.
3. Every AI agent working on the project will automatically index, discover, and obey these rules.
